# Role Handoff Checklist

Use this checklist when work transitions between roles (e.g., PM → Dev, Dev → QA, Dev → Release Coordinator).

## 📦 Context & Documentation
- [ ] Problem statement documented
- [ ] Requirements or acceptance criteria are complete
- [ ] Linked design specs or wireframes included
- [ ] Related issues, dependencies, or blockers listed

## 🔧 Technical Details
- [ ] Architecture/design decisions documented
- [ ] APIs, data models, or schemas attached
- [ ] Performance considerations defined
- [ ] Edge cases and known constraints documented

## 🧪 Testing Expectations
- [ ] Test plan updated
- [ ] Unit, integration, and end‑to‑end test expectations included
- [ ] QA scenarios documented
- [ ] Non-functional requirements defined (perf, load, security)

## 🔐 Security Requirements
- [ ] Security considerations reviewed
- [ ] Sensitive data flows documented
- [ ] Security Handoff Template completed (if needed)

## 🚦 Readiness for Next Role
- [ ] Work validated by current role owner
- [ ] Open questions clarified
- [ ] No blocking dependencies outstanding
- [ ] Next role acknowledged handoff
